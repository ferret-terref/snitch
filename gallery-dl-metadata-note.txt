# gallery-dl: Extracting Gallery Metadata Before Download

To get gallery information (such as image count, title, etc.) before downloading, use the following command:

    gallery-dl -s -j --range 0 <URL>

- `-s` or `--simulate`: Do not download any files.
- `-j` or `--json`: Output metadata as JSON.
- `--range 0`: Only extract gallery info, not individual images.

The output will be a JSON array containing metadata. For example:

[
  [
    2,
    {
      "category": "string",
      "count": 123,
      "site": "web-site",
      "slug": "subpage",
      "subcategory": "gallery",
      "title": "string"
    }
  ]
]

Parse the `count` field for the number of images, and other fields for additional metadata.

This is the most efficient way to pre-fetch gallery info with gallery-dl.
